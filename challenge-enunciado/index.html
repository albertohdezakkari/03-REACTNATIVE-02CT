01CONEXIÓN BÁSICA
HASTA 5 / 10

Haz que React Native reciba un dato real de NestJS

Construye la primera conexión completa entre los dos mundos.

BACKEND · NestJS

Crea un endpoint GET en un Controller que devuelva tu nombre mediante una respuesta JSON.

El nombre debe proceder del backend.

FRONTEND · React Native

Cuando se abra la aplicación, realiza automáticamente la petición al backend, guarda la información recibida y muestra tu nombre en pantalla.

NestJS → GET → HTTP → React Native → estado → interfaz
LO HAS CONSEGUIDO SI…

Tu nombre aparece en React Native y puedes demostrar que procede de la respuesta del backend, no de un texto escrito directamente en la pantalla.

02PATH PARAM + SERVICE
HASTA 7 / 10

Busca alumnos mediante su identificador

Amplía el proyecto anterior. Ahora el frontend decidirá qué alumno quiere consultar.

BACKEND · NestJS

Trabaja con varios alumnos y permite consultar uno concreto mediante:

GET /alumnos/1
GET /alumnos/2
GET /alumnos/3

El Controller recupera el identificador mediante un Path Param y delega en un Service. El Service busca y devuelve el alumno.

La colección y la búsqueda no deben quedar resueltas directamente en el Controller.

FRONTEND · React Native

Añade una forma sencilla de introducir un ID, un botón BUSCAR ALUMNO y una zona visual donde mostrar el alumno recibido.

Cambiar el ID debe permitir recuperar otro alumno desde NestJS.

ID → GET /alumnos/:id → @Param → Controller → Service → JSON → React Native
LO HAS CONSEGUIDO SI…

Puedes cambiar el ID desde React Native y obtener alumnos distintos, demostrando el recorrido completo por Controller y Service.

03LÓGICA EN SERVICE
HASTA 10 / 10

Haz que el backend interprete los datos

Completa la misma aplicación incorporando lógica en el Service.

BACKEND · NestJS

Añade una consulta:

GET /alumnos/:id/nivel

El Controller recupera el ID y delega. El Service localiza al alumno y aplica la lógica necesaria para interpretar su curso/especialidad.

Ejemplo de lógica
DAM → Desarrollo de aplicaciones
DAW → Desarrollo web

La lógica de interpretación no debe estar en el Controller.

FRONTEND · React Native

Reutiliza el ID del alumno y añade una acción CONSULTAR NIVEL. Recibe el objeto del backend y presenta el resultado de forma clara y visual.

Puedes mostrar nombre, curso, especialidad y un mensaje personalizado.

GET /alumnos/:id/nivel → Controller → Service → lógica → JSON → React Native
LO HAS CONSEGUIDO SI…

La aplicación consulta un alumno, el Service aplica la lógica y React Native muestra correctamente el resultado recibido.
