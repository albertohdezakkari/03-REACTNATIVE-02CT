# Ejercicio 04 - Filtra videojuegos

## Qué he aprendido
He aprendido la diferencia entre Path Params y Query Params y a filtrar una colección.

## Respuesta a la pregunta de comprensión
/juegos/3 identifica un recurso; /juegos?genero=aventura aplica un criterio de filtrado.

## Qué he modificado
He creado varios juegos y añadido filtrado por género.

## Resultado
GET /juegos devuelve todos; con ?genero=... devuelve los coincidentes.
