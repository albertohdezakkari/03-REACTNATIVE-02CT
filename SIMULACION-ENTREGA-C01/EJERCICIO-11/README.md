# Ejercicio 11 - Mini tienda

## Qué he aprendido
He aprendido a crear recursos con POST y a recibir datos en NestJS mediante @Body().

## Respuesta a la pregunta de comprensión

## Qué he modificado

## Resultado
POST /productos añade un producto al array temporal y devuelve el nuevo objeto.
