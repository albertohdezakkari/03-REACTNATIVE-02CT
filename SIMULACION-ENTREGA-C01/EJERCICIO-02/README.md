# Ejercicio 02 - API de pizzas

## Qué he aprendido
He aprendido a separar Controller y Service y a usar un array temporal como fuente de datos.

## Respuesta a la pregunta de comprensión
El array está en el Service porque el Controller debe centrarse en recibir HTTP y delegar la lógica.

## Qué he modificado
He añadido una tercera pizza con datos propios.

## Resultado
GET /pizzas devuelve la colección de pizzas desde el Service.
