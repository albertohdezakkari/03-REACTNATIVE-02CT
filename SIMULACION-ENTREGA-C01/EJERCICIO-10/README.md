# Ejercicio 10 - Likes

## Qué he aprendido
He aprendido a utilizar PATCH para modificar parcialmente un recurso y actualizar el estado visual.

## Respuesta a la pregunta de comprensión
PATCH expresa una modificación; el Service cambia el array temporal y devuelve el recurso actualizado.

## Qué he modificado
He añadido un botón de like y actualización del contador.

## Resultado
Cada pulsación incrementa likes mientras el servidor mantiene el array en memoria.
