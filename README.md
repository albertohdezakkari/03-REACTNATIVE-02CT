# C01 · NEST + RN · CONEXIÓN API

## Cuaderno 01 · Del endpoint a la pantalla

Primer cuaderno de una serie de 10 cuadernos de aprendizaje.

### Qué se practica

- NestJS: Controller, Service, endpoints, Path Params, Query Params, GET, PATCH y POST.
- Datos simulados inicialmente mediante arrays en memoria.
- React Native con Expo: fetch, useState, useEffect y FlatList.
- Conexión progresiva Frontend ↔ Backend.
- Cada EJERCICIO-XX es una isla independiente, ejecutable y entregable por separado.

La web docente del cuaderno se publica desde `index.html`.
