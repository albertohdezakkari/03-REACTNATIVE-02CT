# Ejercicio 09 - Busca superhéroe

## Qué he aprendido
He aprendido a construir desde React Native una URL con un id y recuperarlo como Path Param en NestJS.

## Respuesta a la pregunta de comprensión
El id nace en el estado del frontend, entra en /heroes/:id y llega al Controller mediante @Param.

## Qué he modificado
He añadido búsqueda por identificador y una ficha de resultado.

## Resultado
La app muestra el héroe correspondiente al id introducido.
